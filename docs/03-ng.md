## What was cut

**Comments and Javadoc.** The large version is a teaching text; this one is not.
That alone accounts for most of the difference.

**Names.** `weights` → `w`, `gradWeights` → `gw`, `momentum` → `mw`, `sigma` →
`sg`. Identifier length has no effect on bytecode, only on humans.

**Structure.** The `MLP` inner class is gone; the weight arrays are plain static
fields. Methods that were called once got inlined. The `Step` record became three
parallel arrays.

**Whitespace.** One statement per line where possible, no blank lines, minimal
indentation.

## What was *not* cut

Nothing that changes behaviour. Specifically kept:

- the baseline, advantage normalisation and both schedules — remove any of them
  and it stops hitting the optimum
- best-model tracking
- explicit UTF-8 on input and output
- the guard against infinite games
- the exact same prompts, so the two are interchangeable in the test harness

That is the point of this version: **compact ≠ crippled.** Every shortcut is
textual, not algorithmic. A smol file that still plays perfectly.

## When to prefer it

Practically never — read the long version instead. It exists to answer a
different question: *how much of a "big" ML file is actually the model, and how
much is prose?* Answer: about two thirds prose.
